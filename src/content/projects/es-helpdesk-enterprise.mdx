## Sistema modular de soporte

HelpDesk Enterprise es una aplicación para gestionar incidencias de soporte, construida como monolito modular. El backend utiliza Java 21, Spring Boot 3, Spring Security, Spring Data JPA, PostgreSQL y Flyway; el frontend está desarrollado con Angular 21, TypeScript, Bootstrap y RxJS.

El proyecto se ejecuta localmente con Docker Compose y mantiene límites internos explícitos mediante una estructura organizada por funcionalidades. GitHub Actions proporciona el flujo de integración continua.

## Tickets, roles y trazabilidad

Los usuarios se autentican con contraseñas protegidas mediante BCrypt y tokens JWT sin estado. La aplicación define los roles `USER`, `TECHNICIAN` y `ADMIN`, y aplica la autorización tanto en los casos de uso del backend como en la interfaz Angular.

Según su rol, los usuarios autenticados pueden crear y consultar incidencias. Los tickets admiten categorías, prioridades, asignación a técnicos y transiciones de estado explícitas. Los comentarios y un historial inmutable registran acciones relevantes, como cambios de estado o prioridad, asignaciones y comentarios nuevos.

El área administrativa incluye gestión de usuarios y categorías, estadísticas agrupadas de tickets y archivos adjuntos protegidos. Los archivos se almacenan fuera del frontend, se validan y se vinculan al ticket y al usuario; solo se descargan tras autorizar el acceso al ticket correspondiente.

El repositorio contiene la implementación y documentación técnica. Esta ficha no incluye una demo desplegada ni capturas publicadas.
