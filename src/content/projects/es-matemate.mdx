## Ajedrez, entrenamiento y comunidad

MateMate es una aplicación nativa de ajedrez para Android desarrollada en Kotlin como proyecto final de segundo curso de DAM. Combina partidas y entrenamiento con una plataforma orientada a la comunidad.

La aplicación utiliza Stockfish para jugar y analizar partidas con IA, las API de Lichess para datos de ajedrez y problemas diarios, Firebase para autenticación y datos en la nube, y Room para persistencia local.

## Arquitectura y funciones

MateMate sigue una arquitectura de actividad única con Jetpack Navigation. Incluye partidas libres, aperturas, problemas diarios y partidas locales para dos jugadores, además de una biblioteca de aperturas, noticias de ajedrez, notas personales y funciones sociales.

La interfaz incorpora internacionalización y diseños adaptables a teléfonos y tabletas.
