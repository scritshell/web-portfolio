## A focused desktop media downloader

Nebula is a desktop application for downloading video and audio from links supported by yt-dlp. Built with Python and CustomTkinter, it offers MP4 and MP3 output, with FFmpeg used for audio extraction and video merging when available.

The interface retrieves media metadata before downloading, including title, platform, duration and thumbnail. It supports a best-quality video option and a basic 360p option, shows download progress, and provides light and dark themes alongside Spanish and English interface text.

## Organised local output

Downloaded files are stored locally in folders organised by source platform and output format. Nebula also provides direct access to the output folder and can open the completed file or its containing folder from the interface.

The application targets personal and educational use. Users remain responsible for respecting the rights and terms that apply to the content they download.
